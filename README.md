# Mobile Detailing Configurator\n\nInteractieve 3D-configurator voor mobiele carwash / detailing-installaties.\n\n## Features\n\n- Voertuigcategorie + cabine\n- Watertank (210–1000 L) met vlotter\n- Hogedruk, compressor, generator, stofzuiging\n- Modulair frame + haspels\n- Laadruimtebekleding (stof / aluminium)\n- Live 3D (Three.js / R3F) met herkenbare procedurale modellen\n- Pending prijzen (\"Prijs op aanvraag\")\n- 2D fallback\n\n## Tech\n\n- React 18 + TypeScript + Vite\n- Tailwind CSS\n- Zustand\n- Three.js + React Three Fiber + Drei\n\n## Starten\n\n```bash\nnpm install\nnpm run dev\nnpm test\nnpm run build\n```\n\n## Demo\n\nProductgegevens en prijzen zijn demo/pending.
